# 🖥️ PC Forgery

PC Forgery es un proyecto web enfocado en la venta de componentes de computación y en ayudar a usuarios principiantes a armar su propio PC.

El sitio está inspirado visualmente en la interfaz clásica de Windows 98.

## 🛠️ Tecnologías

- HTML
- CSS
- JavaScript

## 📄 Secciones

- Inicio
- Tienda
- Arma tu PC
- Quiénes somos
- Login

## 🎯 Objetivo

Crear una página web responsive utilizando un enfoque **Mobile First**, aplicando los conocimientos adquiridos en HTML, CSS y JavaScript.

## 👥 Proyecto

Proyecto desarrollado como trabajo grupal académico.
